# 脳波ブースター Pro（Gamma Wave Booster Pro）

バイノーラルビートで脳波を誘導し、集中・リラックス・鎮痛・睡眠をサポートするWebアプリです。
インストール不要。スマホのブラウザで開くだけで使えます。

## 📱 スマホで使う（おすすめ）

**公開URL**
```
https://kazu360hikari888ai-glitch.github.io/gamma-wave-booster/
```

### 初回だけ必要な設定（リポジトリ所有者の作業・3タップ）

1. GitHubでこのリポジトリを開く → **Settings**（設定）
2. 左メニューの **Pages**
3. **Source** を `Deploy from a branch` にし、Branch を **`main`** / **`/ (root)`** にして **Save**

1〜2分で上のURLが開けるようになります。以降、mainを更新すると自動で反映されます。

> **検索には出ません。** `noindex` と `robots.txt` を入れてあるため、
> 検索エンジンには載りません。ただし**URLを知っている人は誰でも開けます**。
> やめたくなったら Settings → Pages で配信を停止すれば、すぐにアクセスできなくなります。

> **起動を速くしたい場合（任意）**
> `GitHub Actions` を配信元に選ぶと、JSXを事前変換した軽い版が公開されます
> （「ビルドについて」の節を参照）。ワークフローは手動実行に設定してあるので、
> Actionsタブから `Deploy to GitHub Pages` を実行してください。
> うまくいかなければ `Deploy from a branch` に戻せば元通りです。

### ホーム画面に追加する（アプリのように使う）

- **Android (Chrome)**: 公開URLを開く → 右上の「︙」→ **アプリをインストール**
- **iPhone (Safari)**: 公開URLを開く → 共有ボタン → **ホーム画面に追加**

追加するとアドレスバーのない全画面で起動し、一度開いたあとはオフラインでも動きます（Service Worker）。

> **イヤホン必須**です。バイノーラルビートは左右の耳に異なる周波数を届けることで
> 脳内にうなりを作る仕組みのため、スピーカー再生では効果がありません。

## 🎧 主な機能

- **キャリア周波数 151Hz** をベースにしたバイノーラルビート生成（Web Audio API）
- **9カテゴリ・42モード**（集中・学習／トレーニング／リラックス／気分向上／メンタル改善／健康・痛み緩和／瞑想／睡眠／自動フロー）
- **フローモード**: 時間の経過に合わせて周波数を自動で変化させる多段誘導
- **🫁 呼吸ガイド**: 再生中に呼吸のリズムを視覚表示（後述）
- **📋 セッション記録**: 使用前後のつらさを記録し、効いているモードを集計（後述）
- **⭐ お気に入り**: よく使うモードを星印で登録し、専用タブにまとめる
- **文字サイズ**: 標準／大／特大の3段階（設定画面）
- **終了時の通知**: チャイムとバイブでお知らせ（睡眠系モードは自動で無音）
- **環境音**: せせらぎ・南国の海＋自分の音源を5枠まで登録（IndexedDBに保存）
- **一時停止と停止**: 再生ボタンは一時停止（経過時間を保持し、続きから再開）。
  最初からやり直したいときは隣の停止ボタン
- セッション終了時は3秒かけてフェードアウト（就寝中に音が急に切れない）
- タイマー、バックグラウンド再生、設定のバックアップ／復元

## 🫁 呼吸ガイド

再生中、画面に呼吸のリズムが表示されます。円の膨らみに合わせて息を吸い、縮むのに合わせて吐きます。
数字はそのフェーズの残り秒数です。

| パターン | 比率 | 向いている場面 |
|---|---|---|
| **肩ゆるめ** | 4-2-8 | 肩・肩甲骨のこり。**吐きながら肩をストンと落とす** |
| **4-7-8** | 4-7-8 | 入眠、強い緊張の解除、痛みの鎮静 |
| **ボックス** | 4-4-4-4 | 集中力と冷静さの維持 |
| **整える** | 5-5 | 自律神経のバランス調整。長時間でも疲れにくい |

**「おまかせ」**にしておくと、選んだモードに合ったパターンが自動で選ばれます。
（例: 健康・痛み緩和 → 肩ゆるめ／睡眠 → 4-7-8／集中 → ボックス）
不要なときは「オフ」を選べば非表示になります。

## 💊 肩・肩甲骨の緩和フロー

慢性的な肩こり・肩甲骨まわりの痛みに向けた専用フローです（カテゴリ「💊 健康・痛み緩和」内）。
60分セッションの場合、次のように周波数が推移します。

| 経過 | 周波数 | ねらい |
|---|---|---|
| 0〜8分 | 12 → 10Hz | 緊張のスイッチを切る（SMR波 → アルファ波） |
| 8〜18分 | 10 → 7.83Hz | シューマン共振で交感神経の過緊張を鎮める |
| 18〜30分 | 7.83 → 5Hz | 低シータ波で肩甲骨まわりの深部筋を弛緩 |
| 30〜37分 | 5 → 4Hz | エンドルフィン分泌域へ降下 |
| 37〜51分 | 4Hz 維持 | **鎮痛ホールド（約14分）** ← このフローの中心 |
| 51〜60分 | 4 → 10Hz | 血流の回復を促しながら覚醒へ |

呼吸ガイド「肩ゆるめ（4-2-8）」との併用を想定しています。
時間を10分・20分・30分・90分に変えても、同じ比率でスケールします。

## 📋 セッション記録

どのモードが自分に効いているかを、体感ではなく自分のデータで確かめるための機能です。

1. 再生前に「**いまのつらさ**」を 0〜10 で入力（任意。「—」なら記録しない）
2. セッションを行う
3. 終了すると「いまはどうですか？」と聞かれるので、もう一度 0〜10 で入力

右上の 📋 ボタンで記録を開くと、次が見られます。

- **通算回数 / 直近7日の回数 / 総時間**
- **効いているモード** — モード別の平均改善度ランキング（2回以上使ったモードのみ。
  1回だけの結果はたまたまの可能性が高いため除外）
- **直近20件の記録** — 1件ずつ削除できます
- **CSV書き出し** — Excelでそのまま開けます（全件）

つらさは 0〜10 の NRS（Numeric Rating Scale）方式です。
**記録はこの端末の中だけに保存され、どこにも送信されません。**
機種変更の前にはCSVで書き出してください。

> 1分未満で停止したセッションは、操作ミスとみなして記録しません。

## 🏋️ トレーニング連携

水泳・ランニング・筋トレに合わせた4モードです（カテゴリ「🏋️ トレーニング」）。

| モード | 周波数の動き | 使いどころ |
|---|---|---|
| **運動前・スイッチON** | 10 → 14 → 20 → 30 → 40Hz | ウォーミングアップ中に10〜20分 |
| **ランニング・ゾーン** | 12 → 10Hz で維持 | 走行中。呼吸ガイド「整える(5-5)」と併用 |
| **セット間レスト** | 14 → 11 → 15Hz のV字 | 筋トレのインターバルに2〜5分 |
| **運動後のクールダウン** | 15 → 10 → 7.83 → 6Hz | 運動後10〜20分。回復モードへ切り替える |

短いセッション用に、時間設定へ **3分・5分** を追加しました。

> **水泳では使えません。** 水中でイヤホンが使えないため、水泳は前（スイッチON）と
> 後（クールダウン）で使ってください。
> **ランニング中は骨伝導イヤホンなど、周囲の音が聞こえる機器**を使ってください。

肩まわりが張っている日は、クールダウンのあとに続けて
「💊 肩・肩甲骨の緩和」を行うのがおすすめです。

## ⭐ お気に入りと表示の設定

**お気に入り** — モード一覧の右にある ☆ を押すと登録され、カテゴリの先頭にある
「⭐ お気に入り」タブに集まります。38モードから毎回探す必要がなくなります。

**文字サイズ** — 設定（⚙）から 標準 / 大 / 特大 を選べます。
文字だけでなく余白や行間も一緒に拡大されるので、レイアウトが崩れません。
ブラウザのピンチ操作でも拡大できます。

**終了時の通知** — セッションが終わるとチャイムとバイブでお知らせします。
ただし**睡眠系のモード（熟睡導入・安眠・不安解消・疲労解消・安眠）では、
設定にかかわらず必ず無音**になります。眠りに入るためのモードで音を鳴らしては
本末転倒なためです。

## ⚡ ビルドについて

`index.html` はブラウザ内のBabelでJSXを変換しているため、開くたびに
**Babel本体（数MB）のダウンロードと2,600行の変換**が走ります。

公開版ではこれを事前に済ませられます。Actionsタブから手動でワークフローを実行すると
`build.js` が走り、JSXを変換した `app.js` と、Babelを読み込まない
`index.html` を `dist/` に生成して公開します。**公開版からはBabelが丸ごと消えます。**

`index.html` 自体は書き換えません。そのままブラウザで開いても、
GASに貼り付けても動く状態を保っています。

手元でビルドを試す場合:

```bash
npm install --no-save @babel/core @babel/preset-react
node build.js      # dist/ が生成される
```
